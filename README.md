# 🏠 CampusRent SL 🎓

CampusRent SL is a full-stack web application designed to help university students discover, filter, and contact verified student boarding places near campus.

## 🚀 Features

- **Role-Based Workflows**: Tailored interface for students seeking accommodation and landlords managing properties.
- **Interactive Accommodation Search**: Real-time filtering by room type (Single/Shared), price range, and campus proximity.
- **Landlord Listing Portal**: Modal-driven entry form for property owners to publish new boarding listings dynamically.
- **Direct Owner Messaging**: Integrated WhatsApp API link for instant one-click student inquiries.
- **RESTful API Backend**: Powered by Node.js and Express.js supporting dynamic listing management.

---

## 🛠️ Technologies Used

### Frontend
- **React.js**: Component-based UI library
- **Tailwind CSS**: Utility-first styling framework for responsive design
- **Lucide Icons**: Modern UI iconography
- **JavaScript (ES6+)**: Frontend dynamic application logic

### Backend
- **Node.js & Express.js**: Server-side runtime and RESTful API framework
- **Cors**: Middleware for cross-origin resource handling
